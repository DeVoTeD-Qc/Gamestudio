# KillingCard: UI kit image prompt pack v2

*Author: Sr Game Artist Agent · 2026-11-06 · Board tasks kc-ui-art (v1), kc-ui-art2 (v2: re-based on the card design in the game) · Target: Godot 4.4.1 web (Compatibility), phone landscape 844x390 first, desktop 1440x900*
*For: the studio head (generates in ChatGPT on the phone) and the Technical Artist (cuts, keys, imports).*
*Companion file: `ui-kit-manifest.csv` (one row per image: id, file, category, size, transparency, 9-slice margins, states, where used, priority, final folder, and since v2: status, code id, code hook, code fallback, batch).*

**What changed in v2 (kc-ui-art2).** v1 described the old card parts (number plates, the notched banner frame, the side spine, the serial plate, camo bands on cards, the dog-tag Operator card). The game now has the head's picks from `documentation/ux/card-design-options.html`: **C1+** on the board (full 4:1 art with corner badges: abilities top-right, the FP reticle and the Armor plate bottom-right, traits bottom-left, and the cost hex, level coin and weapon pill top-left on peek), **Y2+** everywhere else (title bar, 4:1 art window, type line, text box, stats bar), the **T1** orders frame for Tactics, and the **O2** Operator card. So v2 **adds {NEW} slots** (the new Pick icon `kw_pick_v2`, the Y2+ / T1 / Operator / Standard Issue card frames, the orders-paper texture, the rail-highlight glow, the damage crack, and optional painted finishes for the reticle, the Armor plate and the level coin), **retires {RETIRED}** (kept in the manifest with the reason: section 4.0), revises `frm_standard_issue` (no cost notch), and **re-plans the batches by visual impact** (section 5). Most of the new card is drawn in code and stays that way: an image slot exists only where an image clearly beats the code, and every entry says whether the code fallback is fine.

**{TOTAL} active images: P1 {P1}, P2 {P2}, P3 {P3}; {DONE} imported (batch 1), {TODO} to make in {BATCHES} batches. {RETIRED} slots retired ({ALL} rows in the manifest).** This pack covers the UI kit around the card art: every icon, button backer, panel, background, and every part needed to build the card frames. The card art itself is not in this pack: the private pitch uses licensed calling cards, the public build uses the banner pack (`banner-art-direction.md`). **Everything here is original**: no logos, brands, franchise insignia, real weapon trademarks, and no text baked in. The game draws every word and number.

What the UI draws today (survey, 2026-11-06): almost all of it is drawn in code. `icon_sheet.svg` holds 34 white line icons (placeholder), `hud_theme.tres` and `card_theme.tres` use flat StyleBoxes, and `banner_view.gd`, `synergy_glyphs.gd`, `strip_badge.gd`, `objective_tile.gd`, `killstreak_row.gd`, `hand_area.gd` and `board.gd` draw badges, plates, bands, ticks and glyphs with `draw_*` calls. The only bitmaps are the Killstreak-era paintings (`title_key_art`, `bg_run`, `bg_supply_drop`, `fx_callin_tablet`, 4 perk patches, 3 square lane backdrops, card art). This pack replaces the code drawing with images where an image looks better, and **keeps the code drawing as the fallback** for every slot.
