# KillingCard art pack 1: prompts for ChatGPT

**ChatGPT, read this first.** This file is a list of image requests for an original card game called KillingCard.
For each image below:
1. Generate ONE image from the text in its "Prompt" block, exactly as written. Landscape 3:2, 1536x1024.
2. Do not add any text, letters, numbers, logos, insignia or real weapon/vehicle models to the image.
3. Give the image the file name shown on its "File" line.
4. If the person asks to redo an image, regenerate it and avoid what its "Avoid" line lists.
Work through one batch at a time, in order. When the person says "Batch N", generate every image in that batch, one at a time.

All art is original. Style: semi-realistic painting with graphic-novel edges, masked or covered faces, fictional gear, one warm light against a cool sky.

Source: `projects/killingcard/documentation/art/da-art-pack-1.md` (full notes, crops and checks for the studio).
