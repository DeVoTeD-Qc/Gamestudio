# KillingCard art pack 1: retry prompts for ChatGPT (4 images)

**ChatGPT, read this first.** This file has 4 image requests for an original card game called KillingCard. They redo images from art pack 1 that were rejected or blocked.
For each image below:
1. Generate ONE image from the text in its "Prompt" block, exactly as written. Landscape 3:2, 1536x1024.
2. Do not add any text, letters, numbers, logos, insignia, real faces or real weapon/vehicle/drone models.
3. Give the image the file name shown on its "File" line.
4. If the person asks to redo an image, regenerate it and avoid what its "Avoid" line lists.
Generate the 4 images one at a time, in order.

Style for all four: semi-realistic painting with graphic-novel edges, every face covered (mask, scarf, tinted goggles or visor), fictional gear, one warm light against a cool sky.

When done, push the 4 PNGs to the same branch and folder as pack 1: `art/killingcard-pack-1`, `projects/killingcard/documentation/art/chatgpt/images/art-pack-1/` (same file names, they replace nothing that shipped).
