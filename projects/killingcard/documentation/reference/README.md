## Head's brief (verbatim summary)
- New project KillingCard: Killstreak as the base; Killstreak and CallingCard stay untouched as backups.
- Give calling cards gameplay value: analyse calling-card style images; image with a character and/or weapon = **unit**, otherwise = **tactic**; the image inspires the effect.
- Many arts per gameplay card (alternate art); not hundreds of unique cards at first.
- Board becomes vertical columns: cards enter from the outside and move toward the objective in the middle, so the frontline unit is obvious.
- Keep the Killstreak mechanics so far (Pick, the Protector sliding to the top on spawn).
- Card layout challenge: calling cards are very wide. On board: probably full calling-card size with icons for stats and effect. In hand: either a centred crop of the image, or a vertical card with the full calling card scaled down as a stripe so it stays recognisable.
- Animated calling cards: animate only when focused or during the placement animation.
- CallingCard project can inspire, but Killstreak's gameplay is preferred.
