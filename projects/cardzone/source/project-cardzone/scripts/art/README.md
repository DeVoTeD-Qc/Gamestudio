# CardZone art kit (cz16)

Procedural placeholder art built from `documentation/art/style-guides/art-direction.md` v1.0 (cz15).
It is adapted from CallingCard's art kit. Everything is code and SVG, with no bitmaps: the kit is about 0.7 MB including the fonts and their imports, against a budget of under 5 MB.

## Files
| Path | What |
|---|---|
| `scripts/art/art_kit.gd` (`CzArtKit`) | Palette tokens, C/U/R/E/L rarity ladder (letter, word, ticks, letter colour), card and tile sizes in pt, floors, `tag_points()` / `draw_tag()` (the clipped tag), `gas_tone()`, `shield_points()`, fonts (`font_display/numeral/body/mono`) |
| `scripts/art/art_icons.gd` (`CzIcons`) | Rasterises marks at the size shown: `get_icon(name, px)`, `silhouette(name, px)`, `area_glyph(id, px, gassed)` |
| `scripts/art/art_icon_data.gd` | GENERATED SVG text (59 icons, 26 silhouettes, 7 area glyphs). Edit `tests/tools/gen_art_icons.py` instead |
| `scripts/art/card_art.gd` (`CzCardArt`) | `read(card)` turns a card Dictionary/Resource into a view-model; draws the art window and the card back |
| `scripts/art/card.gd` (`CzCard`) + `scenes/card/CzCard.tscn` | The card view, compact 84x118 pt and inspector 220x308 pt |
| `scripts/art/area_tile.gd` (`CzAreaTile`) | One area tile, open or gassed, with pips and pawns |
| `scripts/art/map_view.gd` (`CzMap`) | Ridge Hollow: 7 tiles, sea, island and adjacency links |
| `assets/shaders/rarity_glint.gdshader` | Epic / Legendary glint (frame band, stripe and chip only) |
| `assets/themes/cardzone_theme.tres` | Theme, regenerated by `tests/tools/build_themes.gd` |
| `assets/fonts/` | Barlow Condensed SemiBold, Barlow Medium, Share Tech Mono + `OFL-*.txt` |
| `assets/icons/*.svg` | The same marks as files, for TextureRect use |

## Using the card (for cz10)
```gdscript
const CARD := preload("res://scenes/card/CzCard.tscn")
var card: CzCard = CARD.instantiate()
card.size = CzArtKit.compact_px(pt_per_px)      # 84x118 pt; full: CzArtKit.full_px(pt_per_px)
card.configure(CardDB.get_card(&"pump_shotgun")) # CardData, or a Dictionary (tests/tools/art_samples.gd)
card.layout_mode_override = "full"               # "auto" (default: full when >= 150 px wide) | "compact" | "full"
card.held = true        # zone_edge outline + HOLD tag (drawn above the top edge)
card.hold_enabled = true  # 44x44 pt Hold hit area on the top edge toggles held -> hold_toggled(card, held)
card.selected = true; card.dimmed = true; card.face_down = true; card.down = true
card.attachments = ["+1 DMG"]                    # tabs under the card: attachment_tabs_height() px
card.tapped.connect(...); card.inspect_requested.connect(...)  # long-press 0.45 s / right-click
card.layout_report()    # boxes (px), numeral / text px, name fit: use it in layout tests
```
- **Sizes.** Size the card at the 84:118 (or 220:308) ratio. On the 844x390 phone, one logical px is 0.722 pt, so the compact card is 117x164 px. On the 667x375 phone (0.694 pt per px) it is 121x170 px. Don't shrink a card below 84x118 pt: overlap cards instead and keep at least 44 pt of each exposed.
- **Fields `read()` accepts.** These are the cz05 `CardData` properties and `to_dict()` keys, plus aliases:
  - identity: `code`/`id`, `name`/`display_name`, `short_name`;
  - type and rarity: `type` (weapon, item, attachment, hit, marker/bounty), `rarity` (C/U/R/E/L, full name, or "" or "starter");
  - cost: `cost` (0 means no disc), `supply_drop`/`drop`;
  - stats: `brace`, `dmg`, `rng`, `move`, `search`, `heal`, `pull`, `blast_dmg`, `spent`, `ignores_cover`, `fires_per_turn`, `attach_dmg`/`attach_rng`/`attach_extra_fire`/`attach_no_brace` (or `attach: {}`);
  - text and art: `rules_text`/`effect`, `art_key`/`art`, `area`.
- **Supply-drop cost.** A drop with cost 0 shows `CardDB.get_balance().supply_drop_cost` (4 by default), or a card-level `drop_cost`.
- **Down badge elsewhere.** Use `CzCard.draw_down_badge(canvas_item, rect, px_per_pt)` on player panels too.

## Map and tiles
```gdscript
var map := CzMap.new(); map.configure(CardDB.all_areas())   # or art_samples.gd AREAS
map.set_state({"gassed": [&"docks"], "pawns": {&"quarry": [&"player"], &"old_town": [&"ai"]}, "selected": &"quarry"})
map.area_pressed.connect(func(id): ...)
```
- **Tile sizes.** Ring tiles are 120x64 pt and the Core tile is 136x76 pt, so the map's design size is 416x248 pt and it scales to fit.
- **Gas pulse.** A pawn in gas pulses on a 1.2 s cycle; with `Settings.reduced_motion` the ring is static.

## Theme
Set `theme = load("res://assets/themes/cardzone_theme.tres")` on the screen root.

**Palette and constants.** Colours are under the type `CardZone`: every palette token plus `rarity_c..l`. The tap-target constant is `tap_target` = 62 px (44.8 pt).

**Label variations:** Title, Heading, Subheading, Body, Caption, Mono, StatNumber, HitNumber, GasWarning, InkLabel.

**Panel variations:** OpponentPanel, InspectorPanel, GasBanner, PaperTag, HitBadge, RarityChipC..L, CardSlot, CardSlotValid.

**Button variations:** PrimaryButton, DangerButton, GhostButton.

All plates are clipped tags.
