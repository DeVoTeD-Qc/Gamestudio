# CardZone playtest logs

Exported playtest logs for the cz21 internal playtest of the Loadout Loop 1v1 prototype.

## What goes here
- **Real logs:** put each tester's download (`cardzone-playtest-<date>-<sid>.json`) here unchanged.
  - If a tester sends two downloads from the same device, keep both. The tool removes duplicate lines.
  - A download holds every session on that device, including sessions after a reload.
  - For logs sent in the Studio Floor chat, save the attachment here under its original file name.
- **`kpi/`:** the KPI sheet the tool writes (`kpi-sheet.md`, `kpi-sheet.csv`). It is regenerated each run, so don't edit it by hand.
- **`synthetic/`:** **SYNTHETIC test data, not playtests.**
  - Generated by `tools/synthetic_playtest_sessions.gd`, which plays real headless matches (CzAI bots on both seats) through the real logger, with a simulated clock and patched device fields.
  - Every file is named `SYNTHETIC-*` and carries `"synthetic": true`.
  - The KPI tool leaves them out unless you pass `--include-synthetic`. The sample sheet built from them is `synthetic/kpi-sheet-SYNTHETIC.md`.
  - **Never quote these numbers.**

## Privacy
**What a log holds:**
- a random session id;
- the device class, OS family and browser family;
- game events (the human's own cards, and public facts about the AI; never the AI's hidden cards);
- the survey answers, including an optional free-text answer of up to 500 characters.

It holds no names, accounts, IPs or locations.

**Before committing,** read every open answer (shown in the KPI sheet under "Open answer"). If one contains personal details, remove that text from the `open` field and say so in the report.

**If a tester asks for deletion,** delete their file and regenerate the sheet.

## Make the KPI sheet
From `projects/cardzone/`:
```bash
python3 tools/kpi_sheet.py playtest-logs/                 # every real log -> playtest-logs/kpi/kpi-sheet.md + .csv
python3 tools/kpi_sheet.py playtest-logs/ --unit session  # treat every session as its own tester
python3 tools/kpi_sheet.py playtest-logs/synthetic --include-synthetic --out playtest-logs/synthetic/kpi-sheet-SYNTHETIC   # tool test only
python3 tools/test_kpi_sheet.py                           # the tool's self-test
```
The tool uses only the Python standard library (3.9+).
- It checks every line against the schema in `source/project-cardzone/autoload/playtest_log.gd`, the same source the game uses.
- It reads `.json` downloads and raw `.jsonl` logs, and recovers what it can from a cut-off file.
- It reports empty and consent-off logs as "NO DATA" instead of guessing.

Recipes and bars: `documentation/production/playtest-log-schema.md` §5.

## Regenerate the synthetic logs
From `projects/cardzone/source/project-cardzone` (Godot 4.4.1):
```bash
godot --headless --path . -s ../../tools/synthetic_playtest_sessions.gd -- --out=../../playtest-logs/synthetic
```
It writes four personas:

| Persona | Device | What happens |
|---|---|---|
| A | iPhone | 3 matches, with a reload mid-match 2 that is resumed in a second session |
| B | desktop | slow packer; concedes match 2 |
| C | iPhone | 1 match, slow load, survey skipped |
| D | — | consent off, empty |

The generator never touches a real log or save. If the rules, AI or cards change, the matches change too. In that case, update the expected values in `tools/test_kpi_sheet.py::test_synthetic_sheet_values`.
